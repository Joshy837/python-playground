# Looping Through a Dictionary

Use `.items()` to loop through both keys and values at the same time:

```python
scores = {"Alice": 10, "Bob": 8}
for name, score in scores.items():
    print(name, "scored", score)
# Alice scored 10
# Bob scored 8
```
