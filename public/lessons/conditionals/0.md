# Comparing Things

You can compare two values. The result is always `True` or `False`.

```python
print(5 > 3)   # True
print(5 < 3)   # False
print(5 == 5)  # True
```

Common comparisons:
- `>` greater than
- `<` less than
- `==` equal to (two equals signs!)
- `!=` not equal to
