# Repeating a Set Number of Times — range

Use `range(n)` to repeat code exactly `n` times.

```python
for i in range(3):
    print("Hello!")
# Hello!
# Hello!
# Hello!
```

`range(5)` counts `0, 1, 2, 3, 4` — it starts at 0.
