# Looping While True — while

A `while` loop keeps repeating as long as its condition is `True`.

```python
count = 3
while count > 0:
    print(count)
    count = count - 1
# 3
# 2
# 1
```

Make sure the condition eventually becomes `False` — otherwise it loops forever!
